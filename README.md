# PPD Tracker for ASHA Workers

A lightweight, offline-first mobile web app for ASHA workers to track 
postpartum mothers and identify depression risk symptoms.

## Live Demo
🔗(https://lifecourseindia.github.io/lifecourse/)

## Features
- Mother registration & profile management
- Symptom-based risk scoring (EPDS-aligned)
- Color-coded risk badges (Low / Moderate / High)
- Visit history timeline
- One-tap referral to PHC/CHC/District Hospital
- Works offline with browser localStorage

## Tech Stack
- Pure HTML / CSS / JavaScript
- No frameworks, no backend required
- Mobile-first responsive design
